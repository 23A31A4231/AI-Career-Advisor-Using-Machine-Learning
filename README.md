🤖 AI Career Advisor Using Machine Learning
📌 Project Description

The AI Career Advisor is a Machine Learning-based application that helps users discover suitable career paths based on their skills, interests, and strengths.
It uses Natural Language Processing (NLP) and Machine Learning techniques to analyze user input and recommend the most relevant careers. It also provides insights into the skills required for different career opportunities.

✨ Features

- Personalized career recommendations
- Skills and interests analysis
- NLP-based text processing
- TF-IDF Vectorization
- Cosine Similarity for matching skills
- Top 3 career recommendations
- Interactive Streamlit web application
- Real-time user interaction

🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF Vectorizer
- Cosine Similarity
- Streamlit

⚙️ Installation Steps

1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder
cd AI_Career_project

3. Install required libraries
pip install -r requirements.txt

4. Run the application
streamlit run app.py
